# senshi-embers-of-hope
Ein kleines Unity-Spiel mit Hauptmenü, Hauptszene, Cutscenes, Third-Person-Steuerung, Kampf, Inventar und Interaktionen.
Die Szenen heißen u. a. MainMenuScene, MainScene und Cutscene_1 bis Cutscene_4.

**Tech-Stack:**
- Unity 2022.3.11f1
- C#
- Input System
- Universal Render Pipeline (URP)
- Cinemachine
- Timeline
- TextMesh Pro
- UI, VideoPlayer, Visual Scripting

**Hinweis:** Altes, kleines Lern- und Testprojekt, das nicht weitergepflegt wird.
