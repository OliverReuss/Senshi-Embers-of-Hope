Senshi: Embers of Hope is a short, low-poly action-adventure game featuring exploration, NPC dialogues, and a melee combat system. 

> Built as a group project during the 2023/24 winter semester at Hof University. Our goal was to create a vertical slice combining story elements with a custom third-person controller and combat mechanics.

---

## Under the Hood

Instead of relying on a standard top-down template, we built a custom camera-relative third-person controller. The gameplay relies heavily on Rigidbody physics for movement and jumping, while the combat utilizes a raycast-based combo system rather than simple trigger colliders.

---

## Features

* **Third-Person Controller:** Smooth, camera-oriented player movement and rotation.
* **Melee Combat System:** Mouse-driven combo attacks using raycast hit detection.
* **Physics & Platforming:** Rigidbody-based jumping and environmental interactions.
* **NPC Dialogue:** A branching conversation system integrated via Dialogue Editor.
* **Game Loop:** Full scene management, pause menus, and basic crafting elements.

| :--- | :--- |

| **Aim / Camera** | Mouse |
| **Attack** | Left Mouse Button |
| **Jump** | `Space` |
| **Pause** | `Esc` |
